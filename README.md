# 🚀 C++ Journey & Projects Vault

This repository is dedicated to my transition from C to C++, focusing on Object-Oriented Programming (OOP), Data Structures, and advanced logic building. 

## 🗺️ Project Roadmap (Future Builds)

Here are the core projects I am planning to build to master C++ concepts:

### 1. 🏦 Banking & ATM Management System (OOP Focus)
*   **Goal:** Master Classes, Objects, Encapsulation, Polymorphism, and File I/O.
*   **Features:** Account creation, secure deposits/withdrawals, transaction history, and persistent data storage using text/binary files.

### 2. 🧩 Sudoku Solver Visualizer (DSA & Backtracking)
*   **Goal:** Strengthen algorithmic thinking, recursion, and backtracking.
*   **Features:** A command-line tool that takes an unsolved Sudoku grid and visually solves it step-by-step using an optimized backtracking algorithm.

### 3. 📦 Smart Inventory Manager 
*   **Goal:** Deep dive into the C++ Standard Template Library (STL) - Vectors, Maps, and Iterators.
*   **Features:** Real-time stock tracking, product search by ID, sorting by price/quantity, and automated low-stock alerts.

### 4. 🐍 Classic Terminal Snake Game
*   **Goal:** Understand real-time input handling, game loops in C++, and dynamic memory allocation.
*   **Features:** Continuous movement logic, score tracking, collision detection, and increasing difficulty levels.
